# Imágenes de referencia para la UI

Esta carpeta contiene mockups, screenshots o diseños de referencia que definen cómo debe verse la aplicación.

## Uso

- **Onboarding:** Si pegaste imágenes durante el onboarding, guárdalas aquí (arrastra o copia) para que el comando `init-features` las use como base visual al generar las pantallas.
- **init-features:** Lee automáticamente las imágenes de esta carpeta y las usa como referencia principal para layout, componentes y patrones de UI.

## Formato

- PNG, JPG o WebP
- Nombres descriptivos: `dashboard.png`, `lab-reports-overview.png`, `sidebar-collapsed.png`, etc.

## Prioridad

Cuando existen imágenes aquí, tienen prioridad sobre la descripción en `docs/SCREENS.md` para la implementación de la UI.
