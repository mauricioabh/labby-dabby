# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Labby-dabby, please report it responsibly.

**Do not** open a public GitHub issue for security vulnerabilities.

Instead, please email the maintainers with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge your report within 48 hours and provide an update on the status of the fix.

Thank you for helping keep Labby-dabby and its users safe.
